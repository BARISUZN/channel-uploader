Privacy Policy

Last updated: 10 October 2026

Channel Uploader is a private command-line tool used by a single person (its owner) to manage the owner's own YouTube channels. It is not a public service.

What data the tool accesses

With the owner's consent through Google sign-in, the tool accesses the owner's own YouTube account data through the YouTube Data API and YouTube Analytics API: the list of the channel's videos, their titles, descriptions, publication status, captions, comments and statistics. It uploads videos, thumbnails and captions that the owner created.

How the data is used

The data is used only to publish and schedule the owner's videos and to show the owner reports about the owner's own channels. It is not used for advertising, profiling or any other purpose.

Storage and sharing

Access tokens and channel data are stored only on the owner's own computers. No data is sent to any server operated by this tool, and no data is sold, shared or transferred to third parties. The tool has no users other than its owner and collects no data about anyone else.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer removes all stored credentials.
