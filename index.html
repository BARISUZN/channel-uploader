Channel Uploader

Channel Uploader is a private, single-user command-line tool. Its owner uses it to upload videos, thumbnails and captions to the owner's own YouTube channels and to read those channels' own statistics.

The tool is not offered to the public and has no sign-up. It runs on the owner's own computers and talks only to the YouTube Data API and YouTube Analytics API on behalf of the owner's own Google account.
